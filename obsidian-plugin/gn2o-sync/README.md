# GN2O Sync plugin

Copy `manifest.json` and `main.js` into your vault at:

`.obsidian/plugins/gn2o-sync/`

Then enable **GN2O Sync** in Obsidian’s community plugins settings and set the absolute GN2O project path in the plugin settings.

Open a subject hub before running a command. The active note’s basename is used as the subject name.
